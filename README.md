# แบบฝึกหัดเว็บ: ใบงานที่ 1 รูปภาพที่คลิกได้ (Basic Website Design)

เว็บแอปพลิเคชันเพื่อการเรียนรู้และฝึกปฏิบัติการเขียนโค้ด HTML ตาม **"ใบงานที่ 1 รูปภาพที่คลิกได้"** พัฒนาด้วย **React + Vite + Tailwind CSS**

---

## 📋 โจทย์และสถานการณ์ตามใบงาน

> **สถานการณ์:** คุณกำลังสร้างหน้าเว็บแนะนำสถานที่ท่องเที่ยว เขียน HTML ให้หน้าเว็บทำงานตามเงื่อนไขต่อไปนี้

1. **เขียนหน้าเว็บโดยใช้ โครงสร้างพื้นฐานของเอกสาร HTML ให้ครบถ้วน** (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`)
2. **กำหนดชื่อหน้าเว็บว่า "สถานที่ท่องเที่ยว"** (`<title>สถานที่ท่องเที่ยว</title>`)
3. **แสดงรูปภาพจากไฟล์ temple.jpg** (`<img src="temple.jpg" ...>`)
4. **กำหนดข้อความทดแทนของรูปภาพว่า "วัดไทย"** (`alt="วัดไทย"`)
5. **เมื่อคลิกรูปภาพ ให้เปิดหน้า detail.html** (`<a href="detail.html"><img ...></a>`)

**คำชี้แจง:** เลือกใช้แท็กและ Attribute ที่เหมาะสม แล้วเขียนโค้ดด้วยตนเอง โดยไม่เติมคำลงในโครงสร้างที่เตรียมไว้ (เริ่มต้นเขียนโค้ดจากหน้าว่างเปล่า)

---

## 🔐 ระบบเข้าสู่ระบบ (Student Authentication)

ผู้ใช้งานต้องเข้าสู่ระบบก่อนทำแบบฝึกหัด:
- **รหัสนักศึกษา:** ตรวจสอบตามฐานข้อมูล 10 คน (เช่น `67030180`, `67030195`, `67030215`, ...)
- **รหัสผ่าน:** `koson`
- เมื่อล็อกอินสำเร็จ ข้อมูลชื่อและรหัสนักศึกษาจะถูกผูกเข้ากับหัวใบงานโดยอัตโนมัติ พร้อมระบบออกจากระบบ (Logout) และจำข้อมูลโค้ดแยกตามรายบุคคล

## ✨ ฟีเจอร์หลักในระบบ

- 💻 **โหมดฝึกเขียนโค้ด (Interactive Coding Mode):**
  - **ตัวแก้ไขโค้ด (Code Editor):** รองรับเลขบรรทัด 1–14 ตามกรอบใบงานจริง มีปุ่มคีย์ลัดแท็กคำสั่ง จัดระเบียบโค้ด (Auto Format) และคัดลอกโค้ด
  - **ระบบตรวจข้อกำหนดอัตโนมัติ (Live Validator):** ตรวจสอบเงื่อนไขทั้ง 5 ข้อแบบ Real-time พร้อมแสดงคำแนะนำ (Hint) เมื่อเขียนไม่ครบ
  - **จำลองหน้าต่างเบราว์เซอร์ (Browser Preview):** แสดงชื่อแท็บตามแท็ก `<title>`, แสดงผลรูปภาพจริง `temple.jpg`, คลิกที่รูปภาพเพื่อเปิดหน้า `detail.html` ได้จริง พร้อมระบบทดสอบ Alt text
  - **เอฟเฟกต์แสดงความยินดี (Confetti):** เมื่อทำถูกต้องครบ 5/5 ข้อ

- 📄 **โหมดใบงานกระดาษ (Paper Worksheet Mode):**
  - จำลองรูปแบบหน้าใบงานตามเอกสารต้นฉบับเป๊ะ พร้อมช่องกรอกชื่อ-นามสกุล และรหัสประจำตัว
  - เส้นบรรทัดเขียนโค้ด 1 ถึง 14 บรรทัด
  - รองรับการสั่งพิมพ์ (Print) หรือบันทึกเป็น PDF เพื่อส่งครูผู้สอน

- 💡 **เฉลยและคำอธิบาย (Solution & Guide):**
  - อธิบายหลักการของแต่ละแท็กและ Attribute
  - ปุ่มโหลดโค้ดเฉลยเข้าตัวแก้ไขเพื่อทดสอบได้ทันที
